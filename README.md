# Angler Fish Rescue

A tap-to-move underwater reading adventure made for Spencer.

**Play:** https://jayjayro-84.github.io/angler-fish-rescue/

- **iPhone or iPad:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** download the app from https://jayjayro-84.github.io/angler-fish-rescue/download/Angler-Fish-Rescue.apk and tap it to install (it updates the old version and keeps progress). Or open the Play link in Chrome and choose **Install app**.

Open it once with internet and leave it open for a minute so it saves the voices; after that it plays offline.
