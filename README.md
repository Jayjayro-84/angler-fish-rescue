# Angler Fish Rescue

A tap-to-move underwater reading adventure made for Spencer.

**Play / install:** open the GitHub Pages address for this repository on the phone.
- iPhone or iPad: open it in Safari, tap Share, then **Add to Home Screen**.
- Android: open it in Chrome, tap the menu, then **Install app** (or install the APK from Releases).

Open it once with internet and leave it open for a minute so it saves the voices; after that it plays offline.
